# Cuebot gallery

Overlays and widgets for [Cuebot](https://github.com/TechDaddyKB/cuebot), shared by the community. Cuebot lists
them on its **Overlays & Widgets** page (**Browse gallery…**) and imports one with a click.

Each item is a Cuebot overlay package (`.cuebot-overlay`, made with **Share → Export package…** in Cuebot), a
preview image and a short description. Nothing here goes live until a maintainer reviews and merges it.

- **Full guide:** the [wiki](../../wiki) covers creating an item, submitting new and updated items, the checks,
  previews, licenses, reporting and reviewing, step by step.
- **Share yours:** the short version is in [CONTRIBUTING.md](CONTRIBUTING.md).
- **Report an item** (copyright, broken, harmful): [open a report](../../issues/new?template=report.yml). Items
  reported for copyright are taken down while the report is looked at.

Only code the author wrote, or Cuebot's own widgets, may be shared. Widgets bought from a creator (Etsy, Ko-fi,
widget stores) and code imported from StreamElements or Streamlabs are not accepted unless you wrote them.

Each item is shared under the license in its `item.json` (MIT, CC-BY-4.0 or CC0-1.0). The gallery's own tools are
under the MIT license ([LICENSE](LICENSE)).
